# Dino Evolution

Эволюционный алгоритм, который учится играть в динозаврика из Chrome.

Игра бесконечная, поэтому цель — увеличивать пройденную дистанцию и устойчиво переживать разные последовательности препятствий.

## Текущее состояние

Подготовлены TypeScript, Vite и стартовая страница. Игровая механика, нейросеть и эволюционный алгоритм ещё не реализованы.

## Запуск

Нужен Node.js 22.12+ (или более новая LTS-версия).

```sh
npm install
npm run dev
```

Открыть адрес, который напечатает Vite. В Windows PowerShell при блокировке `npm.ps1` использовать `npm.cmd` вместо `npm`.

```sh
npm run typecheck
npm run build
npm run preview
```

После появления `package-lock.json` для воспроизводимой установки использовать `npm ci`.

## Технический подход

- TypeScript, Canvas 2D и Vite; на первом этапе без UI-фреймворка.
- Сначала собственная симуляция с механикой Chrome Dino. Это позволит ускорять обучение и воспроизводить эксперименты по seed.
- Физика с фиксированным шагом, отделённая от отрисовки и частоты кадров.
- Небольшая нейросеть с фиксированной архитектурой; геном — массив её весов и смещений. Для MVP не используем NEAT и изменение топологии.
- Генетический алгоритм: оценка → элитизм → турнирный отбор → скрещивание → мутации → новое поколение.
- Интеграция с оригинальным Chrome Dino — отдельный эксперимент после работающего обучения. Совпадение поведения симуляции и оригинала нужно будет проверить.

## План разработки

### 1. Игровая среда

- [ ] Реализовать бег, прыжок, гравитацию, землю и кактусы на Canvas.
- [ ] Добавить столкновения, дистанцию, ускорение и перезапуск.
- [ ] Добавить ручное управление: пробел / стрелка вверх.
- [ ] Отделить `reset(seed)`, `step(action)` и наблюдение от отрисовки.
- [ ] Ввести генератор случайных чисел с seed и проверить повторяемость.

Готово, когда человек может играть, а одинаковые seed и действия дают одинаковый результат при разной частоте отрисовки.

### 2. Агент и контрольный результат

- [ ] Определить нормализованные входы: скорость, расстояние до препятствия, его размеры, высота динозавра и вертикальная скорость.
- [ ] Реализовать простого агента с правилом прыжка для сравнения.
- [ ] Добавить нейросеть с одним скрытым слоем и действием «бежать / прыгнуть».
- [ ] Добавить кодирование генома и восстановление сети из весов.

Готово, когда оба агента могут играть без клавиатуры, а один геном на одном seed повторяет результат.

### 3. Эволюция

- [ ] Начать с популяции 100 агентов; параметры вынести в конфигурацию.
- [ ] Оценивать fitness по дистанции, ограничить длительность одного эпизода.
- [ ] Проверять агентов на одинаковом наборе seed внутри поколения для честного сравнения.
- [ ] Реализовать элитизм, турнирный отбор, скрещивание и мутацию весов.
- [ ] Разделить случайность среды и эволюции, сохранять настройки эксперимента.
- [ ] Добавить проверки генетических операторов и сохранения элитных особей.

Готово, когда несколько повторных запусков показывают улучшение относительно случайной популяции.

### 4. Наблюдение и эксперименты

- [ ] Показать поколение, число живых агентов, лучший и медианный fitness.
- [ ] Добавить паузу, перезапуск, ускорение и просмотр лучшего агента.
- [ ] Сохранять и загружать чемпиона в JSON вместе с версией формата и конфигурацией.
- [ ] Сравнивать чемпиона с агентом на правилах на отдельных seed, не участвовавших в отборе.
- [ ] При необходимости вынести обучение в Web Worker, чтобы интерфейс оставался отзывчивым.

Готово, когда результат можно сохранить, воспроизвести и сравнить на новых препятствиях.

### 5. Приближение к оригиналу

- [ ] Добавить птиц и действие «пригнуться».
- [ ] Сверить физику, размеры препятствий и скорость с оригинальной игрой.
- [ ] Исследовать способ подключения обученного агента к оригинальному Chrome Dino и проверить перенос.

## Предполагаемая структура

Создаём модули по мере реализации, без пустых заготовок:

```text
src/
  game/        # физика, препятствия, столкновения, наблюдения
  ai/          # нейросеть, геном, агенты
  evolution/   # популяция, отбор, скрещивание, мутации
  rendering/   # Canvas-отрисовка
  ui/          # управление экспериментом и метрики
  main.ts      # точка входа
```

Ближайшая задача: реализовать этап 1 — играбельную среду с воспроизводимой симуляцией.
